# 🎮 遊田ゲーム (Yudai Games)

HTMLで遊べるお金稼ぎゲーム。複数のゲームをプレイして、お金を稼ぎ、自動ツールでさらに稼げるシステムです。

## 🎯 ゲームの特徴

### 🎮 3つのゲームモード

1. **クリッカーゲーム**
   - ボタンをクリックしてお金を稼ぐ
   - 1クリック = 10円（マルチプライヤーの倍率適用）
   - シンプルだが基本的な稼ぎ方

2. **サイコロゲーム**
   - お金を賭けてサイコロを振る
   - **7 or 11** → 大当たり！賭け金の3倍獲得
   - **偶数** → 当たり！賭け金を獲得
   - **奇数** → ハズレ... 次頑張りましょう
   - 戦略が必要な高リターンゲーム

3. **マッチングゲーム**
   - 同じ絵文字のペアを見つけるメモリゲーム
   - 全てマッチさせるとボーナス獲得
   - 完了で 500円（マルチプライヤー適用）

### 🛠️ 自動機能・ツール

1. **自動クリッカー** (1,000円)
   - 毎秒自動でお金を稼ぐ
   - 1台 = 毎秒10円（マルチプライヤー適用）
   - 何台でも購入可能

2. **ゴールドマルチプライヤー** (5,000円 + 段階的に上昇)
   - すべての収入を倍にする
   - 1段階ごとに倍率が上がる（1倍 → 2倍 → 3倍...）
   - 購入コストも段階的に増加

3. **自動セーブ**
   - 10秒ごとにゲーム進度を自動保存
   - オン/オフの切り替え可能
   - ページをリロードしてもデータが復元される

4. **ゲーム統計**
   - 現在のお金と総稼ぎ金
   - ゲーム回数の記録
   - 進捗状況の確認

### 💰 マネーシステム

- **通貨**: 日本円（円）
- **レベルシステム**: 5,000円ごとにレベルアップ
- **データ保存**: ローカルストレージに自動保存
- **リセット機能**: 統計画面からデータをリセット可能

## 🚀 使い方

### インストール

1. ファイルを配置
```bash
YudaiGames/
├── index.html
├── styles.css
└── js/
    ├── game.js
    ├── currency.js
    └── tools.js
```

2. ブラウザで `index.html` を開く

### ゲームの流れ

1. **メニュー画面**からゲームを選択
2. **ゲームをプレイ**してお金を稼ぐ
3. **ツール・自動機能を購入**して収入を増やす
4. **レベルアップ**を目指す

## 📊 進行のコツ

### 初期段階（0 ~ 5,000円）
- クリッカーゲームをプレイしてお金を集める
- 5,000円貯まったら自動クリッカーを購入

### 中盤（5,000 ~ 50,000円）
- 複数の自動クリッカーを購入
- マルチプライヤーレベルを上げてみる
- サイコロゲームで運を試す

### 後半（50,000円以上）
- 自動クリッカーを大量購入
- マルチプライヤーを高レベルまで上げる
- レベル10以上を目指す

## 💾 セーブデータ

ゲームデータはブラウザのローカルストレージに保存されます：

- `yudai_money` - 現在のお金
- `yudai_level` - レベル
- `yudai_autoClickerCount` - 自動クリッカー台数
- `yudai_multiplierLevel` - マルチプライヤーレベル
- `yudai_totalEarnings` - 総稼ぎ金
- `yudai_gameStats` - ゲーム統計
- `yudai_autoSave` - 自動セーブの有効/無効

### データをリセット

ブラウザの開発者ツール（F12）から以下を実行：
```javascript
localStorage.clear();
location.reload();
```

## 🎨 カスタマイズ

### ゲームバランスの調整

`js/game.js` で各ゲームの報酬を編集：
- クリッカー: `currency.addMoney(10 * tools.multiplierLevel)` の `10` を変更
- マッチング: `const reward = 500 * tools.multiplierLevel` の `500` を変更

`js/tools.js` でツール価格を編集：
- 自動クリッカー: `const cost = 1000;` を変更
- マルチプライヤー: `const cost = 5000 * this.multiplierLevel;` を変更

### スタイルのカスタマイズ

`styles.css` で色とレイアウトを変更：
```css
/* グラデーション色を変更 */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* ボタン色を変更 */
background: #667eea;
```
